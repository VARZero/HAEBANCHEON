# RGB DMA 실보드 확인 — 2026-11-11

PZ-A7200T-KFB에 기존 SD4-DMA 비트스트림을 다시 올려 DONE=1, CRC_ERROR=0을 확인했다. UART에서 6.12.0-oryukdo-rgbdma1 커널 및 새 SD 식별자, Linux 셸과 /data 연결을 확인했다.

- 기존 복사·채우기: PASS.
- 새 RGB DMA: 세 페이지 시작 위치에서 691,200바이트 전 바이트 비교, 경계 보호, COW 부모 메모리 보존, 읽기 전용 페이지 거부, 완료 카운터 PASS.
- 단독 검사 DMA 시간: 4.872초, 2.317초, 2.272초. BoAYO 출력 시작 전 검사라 실제 런처 시간과 조건이 다르다.
- BoAYO 실행 후 실제 surface.clear: 11.503544초, 스레드 CPU 6.001869초. 내부 rgb.dma.begin/end도 확인했다.
- 이전 launchtrace-v1 동일 구간: 311.613570초, CPU 156.175275초. 경과 시간 약 27.1배 개선, 96.3% 감소. 계측 출력·스케줄링을 포함한다.
- 현재 도형 그리기 진행 중. 전체 런처 완료·HDMI·WASD의 이번 실보드 검증은 아직 아니다.

새 RTL이나 비트스트림을 만들지 않았다. 입력 비트스트림 SHA-256은 inputs.json, 원본 UART와 프로그래머 기록은 같은 폴더 참조. SD 전체의 실보드 역읽기 해시는 측정하지 않았다. 보드 실행은 계속 유지했다.

배포 당시 result.json/소스 ZIP의 hardware_pending 표시는 당시 검증 상태를 보존한 것이다. 이후 실보드 결과는 본 폴더의 result.json 및 로그가 근거다.
