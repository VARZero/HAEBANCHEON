# tiles-v4 변경·검증 기록

- 기준: tiles-v3 보존. 현재 실보드·HDMI 캡처·UART에는 명령을 보내거나 프로그램을 바꾸지 않는다.
- 메타데이터 upload + present를 BO_PUBLISH로 통합. CPU 스냅샷으로 검증·변경 구간 기록·조건부 전환, 출력 DDR 메타데이터 재읽기 제거.
- 커널 양쪽 메타데이터 사본과 기존 쓰기 API의 보수적 무효화. 사용자 데이터 변경, 활성 버퍼 쓰기, 부분 완료 뒤 잘못된 재사용을 차단.
- BOGPLN02에 사전 계산한 경계 비트마스크 추가. 동적 모양도 변경 때 한 번 계산하여 사용.
- 출력 버전 정리와 통합 요청, 커널의 사용자 복사/검사/업로드/설정/선택/대기/성공 갱신 시간 추가.
- 87.7초의 과거 실보드 내부 항목별 시간은 기존 로그에 없으므로 복원 불가. 새 이미지에서 측정해야 하며 이번 로컬 결과를 실보드 성능 수치로 주장하지 않는다.

검증은 기존 렌더러 픽셀 비교, 타일 재사용, 커널 공통 함수와 DMA 오류 경계, 손상 마스크, ASan/UBSan, 실제 이미지 페이로드 QEMU, 기존 BS25·SD/DMA RTL, 산출물 해시 검사로 구성한다. 확정 PASS/FAIL은 evidence와 result.json에 기록한다. 기존 clocksource의 pr_fmt 재정의 경고는 이번 변경과 별개로 남아 있다.
