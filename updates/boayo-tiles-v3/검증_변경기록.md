# tiles-v3 변경 및 검증 기록

이번 변경은 tiles-v2를 별도 보존하고 진행했다. 현재 실행 중인 보드, UART, HDMI 캡처, RTL, 비트스트림은 변경하지 않는다.

## 변경

- 내장 사전 계산 파일의 본문 CRC·마스크 전수 검사를 이미지 제작 단계로 이동. 실행 시 헤더·버전·범위 검사와 외부 파일 검증 유지.
- 타일별 JSON 문자열 생성/비교를 정확한 정수 버전 목록 비교로 교체. 레이어 순서·배치/모양·타일 내용·포인터 변경 반영.
- 기존 하드웨어를 사용하는 `BO_BATCH` 추가. 128개 이하 Fill/Copy/Blend 요청을 한 번에 복사·검증하고 순차 실행.
- 첫 장면의 44개 배경 Fill 및 44개 경계 합성 요청을 각 1회로 묶음. 변경 없는 장면, 재사용, 전환 뒤 무복사 동작 유지.
- 기존 RV32 worker의 큰 상태 객체를 힙에 두는 수정과 작은 소영역별 내용 버전 추적은 그대로 유지.

## 검증

- 기존 렌더러와 42개 장면 픽셀 비교: 위치·회전·모양·겹침·숨김·재등장·삭제·포인터·작은 내용 수정·반복 단색.
- 별도 7단계 타일 버전/재사용 검증, 초기 88개 작업→2개 묶음 및 무변경 시 요청 0회 확인.
- 실제 커널 공통 코드: 순서 의존 Fill→Copy→Blend, 뒤 항목 오류 시 전체 미실행, 128개 상한, 활성 버퍼 거부, 중간 시간 초과 뒤 재사용 거부.
- 내장 계획은 제작 시 전수 검증. RV32 QEMU 첫 화면 상태에서 builtin_loads=1, payload_scan_bytes=0 확인. 외부 손상 계획은 기존 거부 시험 유지.
- 호스트 기능 9종을 자산 사용/미사용 각각 실행, ASan/UBSan, 실제 SD 페이로드의 RV32 QEMU BusyBox·상위 DDR·BoAYO 앱·WASD/클릭 확인. QEMU BOSIO는 모형이다.
- 기존 BS25 및 SD4/DMA RTL 회귀와 최종 커널·앱·initramfs·ext4·소스 일치성 검사.

## 한계

묶음 요청 안에서도 기존 DMA 완료 대기는 유지한다. CPU가 처리하는 동적 2D 생성, 일부 마스크 경계 워드 수정, 메타데이터, 운영체제/페이지 처리 비용은 남는다. 실보드 첫 화면 시간·HDMI·입력은 새 SD로 별도 측정해야 한다. 실제 통과 결과와 해시는 evidence 및 result.json을 기준으로 한다.
