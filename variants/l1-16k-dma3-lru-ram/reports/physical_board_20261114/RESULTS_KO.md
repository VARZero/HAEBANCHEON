# HAEBANCHEON L1 16KB·DMA3 실보드 최초 부팅 및 첫 화면 측정

2026-11-14, PZ-A7200T-KFB에서 전원이 켜진 상태로 JTAG 비트스트림을 설정했다. 전원 버튼을 누른 순간부터의 측정은 아니다. CPU 50MHz, L1I/D 각각 16KiB·2Way, DMA 3개 구성이다.

## 확인 결과

- FPGA 설정 DONE=1, CRC_ERROR=0.
- Linux `6.12.0-haebancheon-l1-16kdma3-v1`, 이미지 `HAEBANCHEON-L1-16K-DMA3-v1` 확인.
- BusyBox 셸 명령 정상 응답, SD ext4 `/data` 읽기·쓰기 모드로 마운트.
- DMA0/1/2 드라이버 probe 완료. 이번 측정은 3개 동시 스트레스 검증이 아니다.
- BoAYO C++ 실제 BOSIO 백엔드로 실행. 양쪽 투영코어 각각 48개 작업, 96개 타일, 출력 bank 전환 완료.
- DMA 오류·타임아웃 0, render_error/app_error 없음.
- HDMI2 캡처에서 BoAYO 런처와 DASHBOARD / TELEMETRY / SDK PULSE 항목 확인. 작은 글자·경계의 거친 픽셀은 보이며, 전체 화질 정확성 검증까지 주장하지 않는다.

## 시간

| 측정 구간 | 이전 v4 실보드 | 이번 L1·DMA3 + v5 | 비교 |
|---|---:|---:|---:|
| Linux 버전 UART 출력 → 셸 프롬프트 | 194.58초 | 56.84초 | 3.42배 |
| BoAYO 시작 요청 → UART 출력 전환 완료 | 291.41초 | 9.36초 | 31.14배, 96.79% 단축 |

FPGA 설정 완료 → 셸은 62.74초다. BoAYO 시작 요청 → 첫 HDMI 캡처 화면은 11.05초다. 캡처는 초당 2장으로 수집했고 USB/영상 버퍼 지연이 포함되므로 FPGA가 실제 첫 픽셀을 출력한 정확한 시각으로 해석하면 안 된다. 운영체제 부팅 후 사용자가 BoAYO를 실행하는 구간을 별도로 측정했다. 중간에 이미지 확인 명령과 대기 시간이 있으므로 이번 전체 실행의 설정→화면 경과를 자동 시작 부팅 성능으로 제시하지 않는다.

이전은 캐시 없는 SD4·DMA1 하드웨어와 tiles-v4, 이번은 L1·DMA3 하드웨어와 tiles-v5다. 따라서 31.14배는 구성 전체 개선 효과이며 캐시 단독 효과는 분리 측정하지 않았다. 각각 1회 측정이며 반복 분산·장시간 안정성 검증은 아니다.

## 이번 첫 프레임 내부 구간

| 구간 | 시간 |
|---|---:|
| 사전 계산 장면 정보 로드 | 0.298초 |
| 장치 요청 준비 | 0.398초 |
| 텍스처 업로드 | 1.258초 |
| 투영코어 요청·처리 | 1.061초 |
| 타일 버전 처리 | 0.039초 |
| 메타데이터 게시 | 0.406초 |

프레임 처리 시작 기준 출력 완료는 4.111초다. 위 내부 구간은 데몬 시작부터 전체 9.36초의 일부이며, 출력 업로드 전체 구간은 버전 처리·게시를 포함하므로 중복 합산하면 안 된다.

CPU 장면 픽셀 생성 및 결과 다운로드는 0워드다. CPU 출력 메타데이터는 4,480워드다. 경계 타일 44개에 대한 DMA fill 45,056바이트가 있으며 전체 장면 버퍼를 0으로 초기화한 것이 아니다.

## 증거

동일 디렉터리의 `vivado.log`, `uart.log`, `uart_timeline.jsonl`, `result.json`, `hdmi_first_scene.png`, `hdmi_before_scene.png`, `hdmi_usb/frames.jsonl`에 원본 근거를 보관했다. UART live viewer는 COM4를 직접 점유하지 않고 수집 로그를 표시한다.

비트스트림 SHA256: `9bb855886be0ac55d983f9a72ab0e6c23317b7f4fe27e13430cb2de17d7d4e07`

SD 이미지 SHA256(전달 산출물): `7bc6541ea1215ec01780dfc5e372c729c4721d4dde42ceb605df308a2550c333`

SD 카드 전체를 다시 읽어 해시 검사한 것은 아니며 실행 커널과 이미지 식별자를 확인했다. 실행 RTL·Linux·BoAYO 소스는 변경하지 않았다.
